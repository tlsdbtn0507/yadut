# 캘린더 동기화 상세 응답 구현 계획

**목표:** 아르커스가 캘린더 등록에 성공한 각 일정을 날짜와 근무 유형으로 응답한다.

**구성:** 맥 서버는 기존 성공 메시지를 유지한 채 성공한 일정 목록을 `schedules` 필드로 추가한다. 씽크패드는 이 목록만 정해진 아르커스 문구로 포맷한다.

## 작업

1. 씽크패드 테스트에 `schedules`를 받은 성공 응답이 지정 문구로 표시되는 기대값을 추가하고, 실패를 확인한다.
2. 맥 동기화가 실제 등록 성공한 항목 목록을 반환하고 `/sync_calendar`이 이를 `schedules`로 전달하도록 최소 수정한다.
3. 씽크패드가 `schedules`를 포맷해 아르커스 응답으로 반환하도록 수정한다.
4. 관련 pytest를 실행한다.
